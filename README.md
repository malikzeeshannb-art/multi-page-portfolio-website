# Multi Page Portfolio Website — Luxury Redesign

This repository contains a multi-page portfolio website (HTML + CSS) revamped with a refined "luxury" visual style.

## What's changed
- Luxury color palette (deep navy + warm gold accents)
- Improved typography (Playfair Display headings + Inter body)
- Enhanced spacing, shadows, and transitions for a premium feel
- Polished components: hero, cards, gallery, and contact form
- Accessibility preserved and improved where possible (skip link, clear labels)

## Images
- All image file paths remain unchanged (`images/...`).

## How to preview
- Open `index.html`, `case-card.html`, or `contact.html` in a browser.
- The pages use Google Fonts via a public CDN.
